# L1 摘要 Redis 缓存 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 L1 摘要读取路径加 Redis 缓存,消除 `LayeredChatMemory.messages()` 在工具循环内对 MySQL 的 N+1 重复读。

**Architecture:** 缓存放在 Service 层(`MemorySummaryServiceImpl`),对 `LayeredChatMemory` 透明。读路径 cache-aside(命中含空串直接返回,未命中查 MySQL 回填);写路径 write-through(`upsert` 落库后刷新缓存)。用显式 `StringRedisTemplate`(非 `@Cacheable`,规避 `summarizeNow→this.upsert` 自调用绕过 AOP 代理的陷阱)。每个 Redis 操作 try/catch 降级,绝不比纯 MySQL 更糟。

**Tech Stack:** Java 17 / Spring Boot 3 / MyBatis-Flex / LangChain4j / Spring Data Redis(`StringRedisTemplate` 自动装配)/ JUnit 5 + Mockito。

**Spec:** `.claude/plans/2026-05-31-L1摘要Redis缓存-设计.md`
**Branch:** `feat/l1-summary-redis-cache`(非 worktree;延续已提交的 spec)

> **命令约定:** 下列验证命令经 Bash 工具(git bash,含 `grep`)执行;若在 PowerShell 直接运行,把 `| grep -iE "…"` 换成 `| Select-String -Pattern "…"`。

```java
    @Override
    public String getCurrentSummary(Long appId) {
        String cacheKey = CACHE_KEY_PREFIX + appId;
        // 1) 先读 Redis 缓存:命中(含空串)直接返回,堵住工具循环内的 N+1 MySQL 读
        try {
            String cached = redisTemplate.opsForValue().get(cacheKey);
            if (cached != null) {
                return cached;
            }
        } catch (Exception e) {
            log.warn("读取摘要缓存失败 appId={}: {}", appId, e.getMessage()); // 降级:继续查 MySQL
        }
        // 2) 未命中:查 MySQL
        String summary;
        try {
            AppMemorySummary s = summaryMapper.selectOneByQuery(QueryWrapper.create().eq("appId", appId));
            summary = s == null ? "" : StrUtil.nullToEmpty(s.getSummary());
        } catch (Exception e) {
            log.warn("读取摘要失败 appId={}: {}", appId, e.getMessage());
            return ""; // 降级:无摘要,只用 L0
        }
        // 3) 回填缓存(含空串),best-effort
        writeCache(cacheKey, summary);
        return summary;
    }

    /** write-through / 回填缓存,best-effort,失败不影响主流程。 */
    private void writeCache(String cacheKey, String summary) {
        try {
            redisTemplate.opsForValue().set(cacheKey, summary, CACHE_TTL);
        } catch (Exception e) {
            log.warn("写摘要缓存失败 key={}: {}", cacheKey, e.getMessage());
        }
    }
```
