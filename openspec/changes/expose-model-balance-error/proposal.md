# Proposal

## Why

模型账户余额不足目前会被后端通用异常提示覆盖，用户只能看到“系统内部错误”，无法判断应充值。将已识别的余额错误转换为固定中文提示，使前端提供可操作的原因。

## What Changes

- 识别模型 SDK 异常链中的 HTTP 402、明确的余额错误码及明确余额错误信息。
- 在前置 SSE、生成中终态、普通生成与 JSON 异常响应中显示“模型服务余额不足，请充值后重试。”。
- 新产生的失败记录使用相同安全说明，Vue 可信结束原因记录余额不足。
- 不直接透传提供方响应；普通限流、鉴权、超时、输入长度及未知故障保持原提示。前端复用现有展示逻辑并补充回归测试。

非目标：不改变协议字段、错误码、终态枚举、资源释放或记忆生命周期；不改余额、迁移数据库、回写旧历史，也不把可选图片收集失败升级为整轮失败。

## Capabilities

### New Capabilities

- `model-error-presentation`：将已识别模型服务失败转换为一致、明确且受控的用户提示。

### Modified Capabilities

无。现有正式能力未覆盖此错误展示行为。

## Impact

后端异常提示与生成失败收尾、相关 Java 测试及前端会话协议测试。复用 Java 25、Maven、JUnit、现有 JSON 解析库和 Vitest，无新增依赖。风险等级 standard：细化错误展示，不改变安全边界或公共数据结构。
