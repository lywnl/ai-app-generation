- 确认状态：用户明确授权实施。

## 已核实上下文

- 当前配置的路由、生成等模型使用 DeepSeek；`GenerationPreflightException`、Vue 流处理器及普通流处理器会统一使用通用安全提示。
- 前端 `generationSession` 保存 `business-error`／`turn-outcome` 的 message，页面 `outcomeMessage` 优先显示它，故可复用现有展示逻辑。
- 项目 LangChain4j 1.1.0 会将 HTTP 402 包装为 `InvalidRequestException` 并保留原始 `HttpException` cause。
- 最近两次运行日志未发现余额错误原文；用户已在 U2 确认提供方，验证围绕该服务及 SDK 包装行为，不得宣称已复现线上余额不足。

- 验证使用替身，不调用真实收费模型，不修改余额、数据库结构或历史数据；不含自动提交和重启。
