## Why

当前 Vue 生成页面在生成期间仍为网站预览保留固定空间，用户需要在对话和工具消息中寻找计划进度，难以理解计划调整及后续执行。现有 P/E 已维护结构化计划，本期将其展示在原生成页面，并支持重新进入页面时读取当前计划。

## What Changes

- 在现有生成页面提供面向用户的全宽生成工作区：生成期间隐藏网站预览，展示 AI 输出、工具执行记录和当前计划；确认本轮构建成功的终态后恢复对话/代码与网站预览布局。
- 增加计划面板，展示目标、版本、文件用途与动作、触达进度、依赖等待及 Replan 提示；保留既有对话、工具卡片、停止生成、下载和部署功能，沿用现有前端组件及样式约定。
- 在生成会话展示状态中接入现有计划工具和文件工具结果，展示当前回合的创建计划、文件执行、修订及构建记录。`TOUCHED` 表达成功变更，不宣称单文件已经验证通过；工具调用结束不等于执行成功。
- 新增 `GET /api/app/{appId}/plan` 只读接口，以经过权限和生命周期校验的用户视图 DTO 返回当前计划、文件依赖与状态、已有修订记录，供首次打开、刷新和重新进入项目时使用。
- 保留文件工具八字段协议、计划工具结果协议和现有 SSE 类型；以服务端计划为真实状态源，避免前端根据模型文字自行认定计划状态。
- 封闭现有静态资源入口对 `.plan.json`、`.plan-*.tmp` 的直接与绕过读取，计划内容仅通过授权只读接口提供；正常网站 HTML、脚本、样式和图片访问保持公开。

### Non-Goals

- 不修改 P/E 偏差判定、计划创建/修订、成功文件事实写回、构建闸门或软 Replan 执行语义。
- 不提供用户手工修改计划、直接操作 `.plan.json` 或手动调用 `updatePlan` 的入口；Demo 的模拟按钮不进入正式产品。
- 不增加开发者监控页面、诊断接口、完整历史事件存储、数据库迁移或新的前端框架。
- 不改变 HTML、MULTI_FILE 和评测的生成流程，不重新引入已删除的内部输出安全检测。
- 不改构建存储，不增加版本化预览产物；上一版仅尽量保留已加载页面，刷新或资源失效后可显示“上一版预览暂不可用”，不保证历史版本恢复。

## Capabilities

### New Capabilities

- `vue-plan-workspace-ui`: 原 Vue 生成页面的布局切换、用户计划面板、当前回合执行记录，以及计划快照与现有工具事件的展示协同。
- `vue-plan-read-api`: 受应用访问权限约束的只读计划查询，覆盖计划缺失、非法访问、读取生命周期和静态资源旁路阻断，支持页面恢复当前计划。

### Modified Capabilities

- `vue-soft-replan`: 调整“计划摘要必须沿用现有工具展示通道”要求，明确保留工具摘要展示，同时允许本期新增只读计划查询和固定计划面板；其他 P/E 核心要求保持不变。

## Impact

- 前端：主要影响 `AppChatPage.vue`、`generationSession.ts`、计划展示组件、API 客户端及相关 Vitest 测试；需验证桌面和移动端布局、会话切换、停止生成和预览编辑功能。
- 后端：新增 Controller/Service/DTO 查询边界及相应测试，复用计划状态管理能力；必要时增加无目录创建副作用的读取路径，不改变既有写入行为。不向浏览器暴露内部提示词、服务端绝对路径或异常堆栈。
- 静态资源：修改 `StaticResourceController` 及其读取边界，拒绝计划旁车、越界路径和符号链接绕过；不以所有者鉴权替代整个网站的公开预览，不修改构建产物布局。
- 权限与兼容性：延续元数据中登记的 `strict` 等级。重点核验跨应用访问隔离、删除期间读取、既有 SSE 严格解析和工具结果先于终态的发布顺序。
- 数据：继续使用现有 `.plan.json`，不新增数据库表；文件状态变化未必递增计划版本，因此后续设计不能仅靠 `version` 防止前端状态被过期响应覆盖。

### Planning Boundaries

- 现有 `PlanToolResult.status` 是工具调用结果，不是计划整体状态；现有工具事件没有完整的 Replan 状态快照。后续设计需明确查询与事件如何协同，不能把 `REJECTED` 文案或 `APPLIED` 等同于 `REPLAN_PENDING` / `READY_TO_BUILD`。
- 用户已确认第一期复用现有工具事件触发查询，只展示可核验状态与可取得的原因；缺失原因显示通用提示，刷新恢复当前计划及已有修订记录，不扩展偏差历史持久化和推送协议。
- 用户已确认查询及新计划面板仅对登录的应用所有者开放，管理员身份不构成额外授权；失败或取消保留执行区并允许主动查看标注“上一版”的已有预览，只读问答结束恢复原预览且不刷新。
