## 8. 流程交付条件

以下条件不是实施任务，不列为 checkbox，也不构成进入规划评审的循环前置：

- 本变更维持 `strict`。规划齐备后通过 `openspec-review-change` 核对需求、设计和本任务清单，完成独立规划评审并绑定当前规划基线；持续约束与允许修改的源码参考分别登记。
