# 用户需求与已确认决定

## U1：查看他人的应用

- 日期／原始位置：2026-11-03，当前对话及用户提供的应用聊天页截图。
- 必要原文：“现在还有一个优化的点 别人的项目 我可以点击查看对话来看 历史对话和页面都能看到 但是不能修改 现在是看不到 如图”。
- 确认状态：用户明确提出。
- 采纳范围：修复非作者的历史展示和页面预览，禁止普通非作者生成、编辑、部署或其他写操作；完善明确的只读与失败提示，并执行测试。
- 替代关系：他人历史开放范围由 U2 初次明确，再由 U3 收紧。

## U2：开放范围为已部署应用

- 日期／原始位置：2026-11-03，当前对话的范围澄清回复。
- 必要原文：“所有部署的应用”。
- 确认状态：已确认。
- 原采纳范围：不限首页精选；其他登录用户可以查看已成功部署应用的历史和部署页面。此开放范围已由 U3 替代。
- 替代关系：替代澄清问题中的“仅精选”和“所有应用”两个候选范围；后续开放条件由 U3 收紧，其余 U1 约束继续有效。

## U3：收紧为精选且已部署

- 日期／原始位置：2026-11-03，当前对话的修改指令。
- 必要原文：“把部署的改为精选且部署的才能看到”。
- 确认状态：已确认。
- 采纳范围：普通非作者仅能在应用同时为精选且已成功部署时，查看其历史对话和查看页中的发布预览。仅部署、仅精选、二者都不满足均不开放；作者和管理员原有权限保持。
- 替代关系：替代 U2 的“不限精选”开放范围，其余只读、登录、展示字段和生命周期要求继续有效。
- 历史基线：U2 的规划、实现及验收原文已按原始字节保留在 `.codex/enable-deployed-app-readonly-view/baselines/deployed-only/`，`snapshot.json` 保存原路径与哈希；不将旧验收用于证明 U3 已实现。

## 工程范围与授权

本次实施与测试在当前项目内完成。沿用现有登录门槛和管理员管理权限；不开放匿名历史、不开放他人的计划接口和源码下载，不新增存储字段，不自动提交、推送、重启现有服务或生产发布。浏览器验收使用隔离的本机合成数据和构建产物，不访问真实账号数据或模型服务。
