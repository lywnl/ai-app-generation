# 个人博客

围绕“发现文章、阅读正文、继续阅读或了解作者”组织功能，优先保证内容可读和阅读路径连贯。

## 任务规则

1. 首页优先展示文章和必要的作者信息；按当前需求安排最新文章、推荐和分类入口，不用大型宣传区域挤占阅读入口。
2. 列表、详情、分类和搜索共用文章数据与稳定 ID。标题、摘要、日期、标签保持一致，每篇详情有对应正文，并处理文章不存在的情况。
3. 最新文章按日期排序；推荐使用明确的推荐标记或已有热度数据，不编造真实阅读量。演示文章应与博客主题一致，避免所有文章共用占位内容。
4. 搜索与分类条件共同生效，条件变化时重置分页。清空条件恢复列表，区分没有文章与没有匹配结果；返回列表时保留筛选条件和合理的浏览位置。
5. Markdown 仅使用宿主已批准的解析能力，兼顾标题、列表、链接、代码块和图片。缺少解析能力时采用可信演示内容的预渲染展示，不手写完整解析器，不宣称支持任意 Markdown 输入，不将不可信 HTML 直接交给 v-html。
6. 评论按文章 ID 隔离，处理空白、重复提交和失败后的输入保留。没有评论服务时明确本地演示，不能暗示已公开发布或持久保存。
7. 文章、作者介绍和继续阅读入口指向对应内容；作者身份与联系方式来自用户提供的信息或明确示例，不伪造真实履历。

## 本项目边界

遵守宿主 System Prompt、RAG 骨架、依赖白名单和工具协议，不增加依赖或权限。只实现当前需求，局部修改不扩建整站；不调用其他 Skill，不假设浏览器或外部服务可用。缺少后端时明确演示，不伪造认证、保存或发送结果；默认使用简体中文。

## 完成自检

分类后搜索是否正确，详情是否对应文章，文章 A 的评论是否与文章 B 隔离，阅读后能否回到原列表。只声明已有工具结果能证明的验证。
