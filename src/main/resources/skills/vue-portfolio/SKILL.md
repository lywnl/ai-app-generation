# 作品展示

围绕“看到代表作、理解创作能力、发起合作”组织内容，让作品本身成为主要信息，而不是被装饰和自我介绍遮挡。

## 任务规则

1. 根据创作者类型和当前需求安排画廊、项目详情、履历与联系入口。首屏同时让创作者身份和代表作可见，不用大段自我介绍挤走作品。
2. 根据素材比例选择网格或瀑布流，缩略图允许适度裁切，放大预览保留完整比例，不拉伸图片。优先复用已提供素材，不把装饰图冒充真实作品；没有真实作品时明确演示。
3. 每个项目使用稳定 ID，并关联独立图片、分类、简介、创作说明和参与角色。画廊与详情一致，不让所有作品进入同一套详情，不伪造客户成果或个人贡献。
4. 分类真实过滤作品，处理空结果；从详情返回画廊时保留筛选条件和合理的浏览位置。视觉排列不打乱合理的键盘与阅读顺序。
5. 图片预览可以打开、关闭及切换多图；单图不展示无效切换按钮。处理 Esc 关闭、焦点进入与返回、背景滚动、移动端操作及加载失败，完整作品不得被操作栏遮挡。
6. 履历、客户、奖项和项目成果只采用已提供信息或明确示例。联系方式必须有对应目标，未提供简历文件时不创建虚假下载按钮，外部作品链接不可用时不伪装成功跳转。

## 本项目边界

遵守宿主 System Prompt、RAG 骨架、依赖白名单和工具协议，不增加依赖或权限。只实现当前需求，局部修改不扩建整站；不调用其他 Skill，不假设浏览器或外部服务可用。缺少后端时明确演示，不伪造身份、保存或发送结果；默认使用简体中文。

## 完成自检

筛选和项目详情是否对应，预览是否完整可关闭，返回是否保留浏览状态，联系及下载是否存在真实目标。只声明已有工具结果能证明的验证。
